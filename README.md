# GenealogyBot

GenealogyBot is a Windows desktop genealogy research assistant designed to keep family-tree data on the user's PC.

## Download

The public source repository is private. This repository publishes signed Windows installers and the update manifest only. Download the latest installer from [Releases](https://github.com/Nildyanna/genealogybot/releases/latest). The app checks this feed at launch and verifies update signatures before installation.

The app's tree, research notes, and backups remain local. Optional web and FamilySearch features contact their respective services when used.

## Release notes

Each release includes a changelog and versioned installer. Releases contain no personal family-tree information.
